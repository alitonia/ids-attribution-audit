# Results

Campaign outputs. Regenerated by tracked scripts; nothing here is hand-edited.
Directory contents are git-ignored (provenance: RunPod campaign of 2026-08-18
and the fixed full re-run of 2026-08-20; see ITERATION_TRACKER.md).

Contents:

- `exp_{dataset}_{attack}_r{ratio}_seed{s}_K5.json` — the 117-cell campaign:
  3 datasets (cic = CIC-UNSW-NB15, nf = NF-ToN-IoT, ciciot2023 = CICIoT2023)
  x 3 attack families + clean (`attack=none`) x rho in {1,2,5,10}% x seeds
  0-2, K=5 checkpoints. 108 poisoned cells + 9 clean cells. Each JSON holds
  poisoned/quarantined metrics, per-class recall, localization AUROCs and flag
  precision for all methods (trak, tracincp, loss_outlier, grad_norm,
  activation_clustering, random, oracle), and error records.
- `*_smoke.json` — small-scale validation runs (excluded from aggregation).
- `rs_results.json` — Cohen randomized-smoothing certificates (sigma=0.5,
  N=200) for all 117 cells: per-class certified accuracy at r in
  {0, 0.25, 0.5, 0.75, 1.0}.
- `smoke_*.log`, `trak_inversion_diagnosis.*` — validation and diagnosis
  provenance for the pre-registered protocol decisions.

Aggregation (run from the repo root, project venv):

    .venv/bin/python aggregate_latex.py --method tracincp
        -> results_table.tex, baseline_table.tex
    .venv/bin/python generate_figures.py
        -> rs_radii_table.tex, paper/fig_auroc.pdf, paper/fig_rs_radii.pdf

paper/main.tex \input's the three tables from this directory's parent.
